# 🚀 ICO Converter Pro

A powerful and lightweight desktop tool to convert images (`JPG`, `PNG`, `JPEG`, `BMP`) into high-quality `.ICO` files.

Built with Python, designed for simplicity, speed, and real-world usability.

---

## ✨ Features

* 🖼️ Convert multiple image formats to `.ico`
* 📂 Batch conversion support
* 🖱️ Drag & Drop interface
* 🧠 Automatic square resizing for best icon quality
* 🧾 Real-time conversion logs
* 🧰 Clean and minimal GUI (Tkinter-based)
* 🔔 System tray support (minimize & restore anytime)

---

## 🛠️ Tech Stack

* Python 🐍
* Tkinter (GUI)
* Pillow (Image Processing)
* Pystray (System Tray Integration)
* TkinterDnD2 (Drag & Drop Support)

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/ABSMPSOM/ICO-Converter.git
cd ico-converter-pro
```

Install dependencies:

```bash
pip install pillow pystray tkinterdnd2
```

---

## ▶️ Usage

Run the application:

```bash
python main.py
```

### How to use:

1. Drag & drop your image files into the app
2. Or click **Browse** to select files
3. Click **Convert All**
4. Your `.ico` files will be generated automatically

---

## 📁 Supported Formats

* `.png`
* `.jpg`
* `.jpeg`
* `.bmp`

---

## ⚙️ Build EXE (Optional)

To convert into a standalone executable:

```bash
pip install pyinstaller
pyinstaller --onefile --noconsole main.py
```

Output will be available in the `dist/` folder.
